# Serein — Stay a Little Closer ✨

A premium hospitality website concept designed to inspire meaningful getaways, thoughtfully curated stays, and slower moments of living.

🌐 **Live Website:** https://serein-studio-phi.vercel.app

💻 **GitHub Repository:** https://github.com/Gunnjann/serein-studio

## ✨ About the Project

Serein is a fictional hospitality brand built around the idea that the best stays are about more than just a place to sleep — they're about comfort, connection, discovery, and the little moments that make a trip memorable.

The website brings together an elegant visual identity, an immersive browsing experience, and a calm, modern aesthetic to make discovering a getaway feel special.

## 🎨 Design Direction

- Premium, minimal visual style
- Elegant typography and spacious layouts
- A hospitality-inspired, editorial aesthetic
- Thoughtful presentation focused on comfort and discovery
- Responsive design for different screen sizes

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Vercel for deployment

## 📂 Project Structure

serein-studio/

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Gunnjann/serein-studio.git
   ```

2. Open the project folder and navigate into the nested `serein-studio` directory.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
