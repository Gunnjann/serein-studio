# Serein — Premium stay collection website

A responsive, motion-led fictional hospitality brand website built with semantic HTML, CSS, and vanilla JavaScript. No build step or package installation is required.

## Run locally
Open `index.html` in a modern browser, or serve this directory with a static server (for example, `python -m http.server 8000`).

## Included interactions
- Staged loading and hero entrance
- Intersection-based scroll reveals (with reduced-motion fallback)
- Responsive mobile navigation
- Expandable process steps
- Accessible native dialog for the signature experience
- Three working editorial article dialogs
- Client-side inquiry form validation and confirmation state
- Responsive layouts for desktop, tablet, and mobile

## Notes before production
- Photography is loaded from Unsplash URLs; replace with licensed/local optimized assets for a production deployment.
- The inquiry form currently validates locally and displays a confirmation. Connect it to a booking inbox or backend before accepting real enquiries.
- `hello@sereinstays.example` is a deliberately non-production example address.
